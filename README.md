# تقرير الحضور والتحضير

أداة ويب ثابتة تقرأ تقريري نقار (تحضير دروس المعلمين وغياب الحصص للطلاب) بصيغة PDF أو Word، وتعبّئ استمارة متابعة التعليم عن بُعد، وتستخرج كشوف الغياب والإحصائيات بصيغ Word وPDF وExcel.

الموقع المنشور: https://blatshf02.netlify.app

## البنية
| المجلد | المحتوى |
|---|---|
| `site/` | الملفات المنشورة كما هي على Netlify (تُولَّد تلقائيًا، لا تُعدَّل يدويًا) |
| `src/` | المصدر: واجهة الصفحة، منطق قراءة الملفات، والاستمارة |
| `tooling/` | المكتبات والخطوط بإصدارات مثبتة، وسكربت البناء والفحص الأمني |
| `netlify.toml` | إعدادات النشر ورؤوس الأمان |

## التعديل والنشر
```bash
cd tooling
npm ci --ignore-scripts
python3 build.py      # يولّد site/ من src/
bash verify.sh        # فحوص الأمان
```
ثم افتح طلب دمج (Pull Request) إلى `main`. بعد نجاح الفحص الآلي والدمج، ينشر Netlify التحديث تلقائيًا.
